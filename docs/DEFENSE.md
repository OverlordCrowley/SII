# Сценарий защиты проекта

Тема: ИИ-помощник по диагностике неисправностей компьютера.
Продолжительность выступления: примерно 7–10 минут.

## Начало выступления

«Моя программа анализирует описание симптомов компьютера и предлагает
возможные причины неисправности. Проект демонстрирует модели знаний,
изученные в курсе: логику, продукционные правила, фреймы и семантическую
сеть. Для сравнения я добавил наивный байесовский классификатор и
простую нейросеть. Пользователь видит, какие наблюдения и правила
подтверждают гипотезу».

## Порядок показа

| Время | Что показать | Что объяснить |
|---|---|---|
| 0:00–1:00 | Тема и цель | Диагностика хорошо подходит для правил и связей |
| 1:00–2:00 | Архитектура и `knowledge.json` | Один словарь симптомов для всех модулей |
| 2:00–3:30 | Пример памяти | Два последовательных правила и исходное отрицание |
| 3:30–4:30 | Фреймы и сеть | Наследование ОС и поиск пути от симптома к компоненту |
| 4:30–6:00 | Датасет и модели | Групповой split, validation, accuracy и F1 |
| 6:00–7:00 | Неполный запрос | Неизвестное отличается от отрицания |
| 7:00–8:00 | Тесты и результаты | Границы ввода, циклы, сохранение, воспроизводимость |

## Команды демонстрации

Откройте терминал в папке проекта. В Windows можно заменить
`python -m pc_assistant` на `run.bat`.

```powershell
python -m pc_assistant ask "Компьютер включается, черный экран, пищит"
python -m pc_assistant ask "Компьютер включается, черный экран"
python -m pc_assistant frames show office_pc
python -m pc_assistant network path disk_noise storage
python -m pc_assistant ask "Компьютер перегревается, вентилятор шумит, сам выключается"
python -m unittest discover -s tests -v
```

В первом примере R02 выводит проблему изображения, затем R03 —
гипотезу о памяти. Во втором нет факта `beeps`: без него программа
не выбирает между R03 и R04. В третьем покажите `origins`: Windows
приходит от `computer`, а 16 ГБ RAM заданы в `office_pc`. Сеть
соединяет щелчки диска с гипотезой и накопителем.

## Ответы на вероятные вопросы

**Где здесь искусственный интеллект?** В формализации знаний,
автоматическом выводе новых фактов, объяснении и обучении моделей
по примерам. Анализ текста ограничен явно заданным словарём.

**Чем факт отличается от правила?** Факт описывает конкретное
наблюдение. Правило связывает условие и новое заключение для любого
случая, в котором условие подтверждено.

**Чем прямой вывод отличается от обратного?** Прямой вывод начинает
с фактов и выводит все доступные заключения. Обратный начинает
с выбранной цели и ищет доказательство по правилам.

**Почему не применяется NOT к неизвестному?** Неизвестное наблюдение
может оказаться истинным или ложным. Поэтому его отрицание тоже
неизвестно. Явное «не перегревается» превращается в `high_temp=false`.

**Как завершается цикл правил?** Прямой вывод добавляет каждый факт
один раз и прекращается, когда новые заключения закончились.
Обратный вывод хранит посещённые цели и прерывает рекурсивный цикл.

**Чем фрейм отличается от семантической сети?** Фрейм группирует
свойства объекта и наследует значения. Сеть хранит типизированные
связи между объектами и позволяет искать пути.

**Что значит 96,3% точности?** Это доля правильных ответов MLP на
244 тестовых синтетических примерах. Результат нельзя переносить
на настоящие компьютеры без отдельного реального исследования.

**Почему нужен validation?** Чтобы выбрать веса, не используя
итоговые тестовые ответы. MLP сохраняет эпоху с минимальной
валидационной кросс-энтропией.

**Почему иногда правило и модель расходятся?** Правило описывает
конкретные условия, а модель использует распределение учебных
признаков. Система показывает их отдельно и сохраняет объяснение.

**Что можно улучшить?** Собрать реальные случаи, расширить словарь,
добавить оценку неопределённости, проверять сочетания неисправностей
и автоматизировать получение наблюдений с согласия пользователя.

## Перед сдачей

Заполните личные данные в `docs/LABS.md`. Опубликуйте проект в своём
GitHub и подставьте настоящие ссылки. Проверьте `run.bat demo` на
компьютере защиты. Откройте PPTX и при необходимости добавьте своё
имя и группу на титульный слайд. Саму защиту студент проводит лично.
