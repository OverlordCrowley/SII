# Соответствие семестровому заданию

Источник требований: сообщение преподавателя о неделях 4–15 и файл
«Лабораторные_работы_СИИ.docx». Выбрана предложенная в файле тема
«Помощник по диагностике неисправностей компьютера».

| Требование | Реализация | Проверка |
|---|---|---|
| Работающая Python-программа | Команды `chat`, `ask`, `demo` | Семь демонстрационных запросов и тест CLI |
| База знаний | JSON: 18 симптомов, 7 гипотез, 23 правила | Загрузка, уникальность идентификаторов |
| Логический вывод | Обратный вывод по цели | Сравнение с прямым выводом на всех демо |
| AND, OR, NOT и объяснения | AST, трёхзначная логика, деревья доказательств | Таблица истинности, неизвестные факты, выбор ветви OR |
| Не менее 10 продукционных правил | 23 правила, приоритеты, фиксированная точка | Цепочки R02/R03/R19 и R10/R11/R22 |
| Фреймы с наследованием | 15 фреймов, слоты, экземпляры | Наследование, переопределение, поиск и сохранение |
| Сеть с 10 узлами и 10 связями | 22 узла и 22 направленные связи | BFS, фильтр отношения, обратный проход |
| Датасет и классификатор | Синтетический CSV, Bernoulli Naive Bayes | Групповой split, метрики и матрица ошибок |
| Нейросеть и оценка | MLP 18–16–7, tanh и softmax | Валидация, сохранённые веса, тестовые метрики |
| Экспертная система | `ExpertSystem` объединяет все модели | Сценарии консультаций и проверка сохранения |
| ИИ-помощник | Словарь фраз, анализ запроса, ответ и уточнения | Отрицания, неполный ввод, противоречия |
| README и материалы защиты | Документация, отчёты, PPTX, сценарий | Воспроизводимые команды и реальные результаты |
| GitHub и коммиты | Локальный Git, отдельные коммиты этапов, CI-файл | `git log`; удалённая публикация ещё не выполнена |
