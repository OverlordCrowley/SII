# Проверка кода

Проверка выполнена при подготовке итоговой версии. Это внутренний
анализ реализации и автоматические тесты, а не независимое ревью
преподавателя или другого разработчика.

Проверялись логическая корректность, обработка неполного ввода,
циклы, объяснения, наследование, хранение изменений и разделение
обучающей и тестовой выборок.

| Обнаруженный случай | Исправление | Подтверждение |
|---|---|---|
| Объяснение OR могло включать неизвестную ветвь | Отбор подтверждающих посылок через `support_atoms` | `test_or_explains_only_supported_branch` |
| Сложное отрицание требует свидетельства ложности подвыражения | Рекурсивный выбор ветви с учётом ожидаемого значения | `test_negated_compound_explanation` |
| Поиск пустого слота мог совпасть с None | Проверяется наличие слота и точный тип значения | `test_find_distinguishes_absent_and_null` |
| Неизвестный симптом нельзя считать отрицанием | Трёхзначная логика и вопросы пользователю | `test_unknown_is_not_false`, `test_demo_scenarios` |
| Поздний факт мог отменять NOT над выводимым атомом | Такая база правил отклоняется при загрузке | `test_nonmonotonic_negation_rejected` |
| Одинаковые векторы могут создавать утечку данных | Split по SHA-256 группы вектора | `test_group_split_has_no_leakage` |

Итоговая проверка: `python -m unittest discover -s tests -v`.
Дополнительно выполнены демонстрационные сценарии, повторное обучение
и проверка метрик из сохранённых весов. Ограничения учебной модели
описаны в README и не скрываются числом accuracy.
