Локальная экспертная система на Python. Помощник разбирает сведения
о продукте, спросе, команде, токене, предложении, разблокировках и
безопасности. Выдаёт замечания, уточняющие вопросы и деревья объяснений.

## Запуск

В Windows откройте **run.bat** двойным щелчком. Интерфейс откроется
в браузере: `http://127.0.0.1:8765`. Окно запуска оставьте открытым;
для остановки нажмите Ctrl+C. Скрипт использует Python из `.venv`,
доступный runtime Codex или системный `py -3`.

На любом компьютере с **Python 3.10+**:

```powershell
python -m project_assistant
```

Дополнительные пакеты и API-ключи не нужны. Если порт занят:

```powershell
python -m project_assistant serve --port 8766
```

## Использование

1. Введите название, сеть, контракт или нативный актив и описание.
2. Откройте группы критериев и задайте «Да», «Нет» или «Неизвестно».
3. Добавьте основания, источники и даты. Явные фразы из описания
   распознаются по словарю: «продукт работает», «у проекта есть токен»,
   «vesting не раскрыт», «аудит опубликован».
4. При наличии чисел заполните «Числа и разблокировки»: денежные
   показатели в USD, предложение и unlock в токенах, дату и источник.
5. Нажмите «Проанализировать». Разберите рекомендации и «Показать объяснение».
6. Сохраните Markdown-отчёт и JSON-профиль. Профиль можно открыть повторно.

Текущая форма автоматически сохраняется как черновик в этом браузере:
название, описание, числа, ответы, основания, источники и даты. После
перезагрузки можно продолжить ввод или повторить анализ. Кнопка «Очистить»
удаляет черновик. Он привязан к браузеру и адресу приложения; JSON-файл
нужен для переноса на другой компьютер или сохранения отдельной версии.
При запрете хранения интерфейс предлагает экспортировать профиль в файл.

В поле «Название» или «Тикер» можно ввести полное название, тикер или
русский вариант: `Bitcoin`, `BTC`, `биткоин`; `Ethereum`, `ETH`, `эфириум`;
`Solana`, `SOL`. Регистр букв и лишние пробелы не важны, поддерживается
форма `$BTC`. После анализа поля и отчёт содержат единое название и тикер.
При смене монеты автоматически подставленное поле обновляется; если оба
поля заполнены вручную разными монетами, помощник попросит уточнить ввод.

Локальный [справочник алиасов](data/asset_aliases.json) содержит 29 монет
и доступен для дополнения. Неизвестные названия сохраняются как введены.
Распознавание имени не подставляет рыночные данные, сеть, адрес или ответы
на критерии. Те же алиасы работают при импорте JSON и в CLI:

```powershell
python -m project_assistant ask BTC
python -m project_assistant ask "Эфириум"
python -m project_assistant ask "Продукт работает" --name Solana
```

Если после анализа изменить поля, интерфейс отметит, что результат устарел.
При сохранении отчёта или профиля помощник автоматически повторит анализ
и сохранит последние правки. Некорректные данные нужно исправить до сохранения.
Если изменить форму во время анализа, помощник предложит повторить обработку.
Очистка или выбор другого примера отменяет предыдущий запрос.

Можно открыть описание `.md`, `.txt` или профиль `.json` в UTF-8, до 256 КБ.
Пустой, повреждённый или неподходящий файл отклоняется с объяснением;
предыдущая форма сохраняется. Пользовательский HTML и Markdown в отчёте
экранируется и выводится как текст. Файлы и ссылки
обрабатываются как данные; содержащиеся в них инструкции не исполняются.
Ссылки сохраняются как источники. Содержание сайтов и живые котировки
автоматически не загружаются.

Если сервер недоступен при запуске, кнопка «Повторить подключение»
повторно загружает базу без потери введённого названия. Обычный запрос
ограничен 15 секундами; ожидание языковой модели учитывает её отдельный
таймаут. После ошибки можно повторить действие. Некорректное поле
раскрывается, получает фокус и сопровождается сообщением на русском.

## Реализовано

- **26 критериев, 28 правил** в редактируемой базе JSON.
- Продукт, реальные пользователи, спрос, экономика и конкуренты.
- Связь использования продукта с ценностью токена и права держателя.
- Supply, эмиссия, распределение, vesting, unlocks и концентрация.
- Код, аудит, полномочия администраторов и история инцидентов.
- Ликвидность, сравнение оценок, источники и даты метрик.
- Прямой продукционный и обратный логический вывод.
- AND, OR, NOT, скобки, неизвестные значения и минимальные объяснения OR.
- Фреймы с наследованием и редактированием; сеть **22 узла, 21 связь**, BFS.
- Браузерный интерфейс, CLI, отчёт, импорт и экспорт профиля.
- Восемь тем и компоновок с превью и сохранением выбора.
- Автосохранение черновика и восстановление после перезагрузки.
- Три вымышленных учебных проекта: полный, проблемный и неполный.

Это классический ИИ в форме экспертной системы. Произвольные формулировки
не всегда распознаются; их нужно уточнить в анкете. Введённые сведения
сохраняются локально в черновике браузера и в явно экспортируемых файлах.

## Расчёты и единицы

| Показатель | Формула |
|---|---|
| Капитализация | Цена USD × circulating supply |
| FDV | Цена USD × выбранный total или max supply |
| Доля обращения | Circulating / выбранная база FDV × 100% |
| Доля unlock | Объём unlock / circulating supply × 100% |
| Объём / капитализация | Объём 24ч USD / капитализация USD × 100% |

База FDV выбирается явно. Определения капитализации и FDV сверены
с материалами [CoinGecko о капитализации](https://www.coingecko.com/learn/what-is-market-cap-in-crypto)
и [FDV](https://www.coingecko.com/learn/what-is-fully-diluted-valuation-fdv-in-crypto).
Разные определения supply могут давать разные значения FDV, поэтому
база сохраняется в профиле и отчёте.

Пустое значение остаётся неизвестным; явный ноль сохраняется. Если результат
выходит за точность вычислений, показатель остаётся неизвестным с предупреждением.
Очень малые и большие значения отображаются в научной записи. USDT
не подставляется вместо USD. Если капитализация или FDV источника
отличаются от расчёта больше чем на 1%, выводится сообщение, а сигнал
по отношению FDV/капитализация не формируется до уточнения.

Учебные пороги: FDV/капитализация ≥3; обращение <25% базы FDV;
будущий unlock ≥10% обращения. Это фиксированные эвристики для
объяснимых сигналов, без предсказания движения цены. Нужны дата снимка
и дата unlock позже снимка, иначе сигнал будущей разблокировки не выводится.

## Как понимать оценку

Балл показывает **проработанность анализа по введённым сведениям**.
Нижняя граница учитывает известные положительные критерии, верхняя —
допускает положительные ответы по неизвестным. Веса открыты в базе знаний.
При явном отсутствии собственного токена токеномика исключается.
Неприменимые сведения о токене сохраняются в профиле и не участвуют в выводах.
Численные сигналы выводятся отдельно от балла.

Помощник не подтверждает введённые утверждения независимой проверкой.
Он не оценивает доходность и не предсказывает цену. Аудит, капитализация
и учебный балл сами по себе не подтверждают безопасность актива.

## CLI и проверка

```powershell
python -m project_assistant analyze examples/risky.json
python -m project_assistant analyze examples/ready.json --json
python -m project_assistant analyze examples/ready.json --output crypto-report.md
python -m project_assistant ask "У проекта есть токен. Vesting не раскрыт. Аудит опубликован."
python -m project_assistant demo
python -m project_assistant week56
python -m unittest discover -s tests -v
```

Для разработки есть 10 тестов хранения черновика, ошибок соединения,
формата ответа, таймаута и отмены. Нужен Node.js 22+:

```sh
node --test tests/frontend.test.cjs
```

Они проверяют функции из настоящего интерфейса с подставленными сбоями.
Полные пользовательские сценарии проверены отдельно в браузере;
см. [итоговый отчёт, 40 компоновок и доказательства](docs/FINISHED_QA_2026_10_07.md).
Node.js не нужен для запуска приложения.

`--output` создаёт новый файл и предотвращает случайную перезапись.
Формат профиля показан в `examples/ready.json`. Типы: `crypto_project`,
`defi`, `layer1`, `layer2`, `infrastructure`, `gaming`.
Факты: `true`, `false`, `null` либо объект с `value`, `evidence`, `source`,
`date`. Дата имеет формат YYYY-MM-DD. Анкета имеет приоритет над описанием.

## Структура

- `project_assistant/assistant.py` — анализ, вопросы и отчёт;
- `logic.py`, `production.py` — обратный и прямой вывод;
- `tokenomics.py` — валидация и расчёты чисел;
- `frames.py`, `network.py` — фреймы и семантическая сеть;
- `expert.py`, `workbench.py` — объединённый вывод и команды изменения знаний;
- `dataset.py`, `ml.py`, `models/` — синтетические данные, обучение и сохранённые модели;
- `server.py`, `web/index.html` — локальный сервер и интерфейс;
- `local_ai.py` — необязательный клиент локального llama.cpp;
- `data/knowledge.json` — критерии, правила, связи;
- `data/asset_aliases.json`, `assets.py` — названия, тикеры и их распознавание;
- `examples/` — три вымышленных профиля;
- `tests/` — проверки логики, расчётов, отчёта и HTTP API.
- `presentation/` — презентация для защиты недель 4–15.

Механизмы логики, продукций, фреймов и сети входят в Криптоскоп
и работают без других проектов и внешних зависимостей.
