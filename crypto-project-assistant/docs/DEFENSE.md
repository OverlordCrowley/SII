## Ответы на вопросы

**Почему это экспертная система?** Знания отделены от механизма вывода.
Система применяет правила к рабочей памяти, получает промежуточные заключения
и показывает посылки каждого результата.

**Чем отличаются прямой и обратный вывод?** Прямой расширяет факты из условий
правил. Обратный начинает с цели и проверяет необходимые посылки.

**Что означает неизвестно?** Сведений недостаточно. Это не доказательство
отрицательного факта. Помощник формирует уточняющий вопрос.

**Что обучает нейросеть?** Классификацию комбинаций фактов по статусам
исследования. 58 входов, 16 скрытых нейронов tanh, четыре выхода softmax.
Веса меняются методом SGD по перекрёстной энтропии.

**Можно ли считать 99% качеством оценки монет?** Нет. Это точность на 201
синтетическом примере, размеченном экспертными правилами. Реальные исходы
не измерялись. Поэтому модели показываются для сравнения с объяснимым выводом.

**Почему Байес ошибается чаще?** Он предполагает условную независимость
признаков внутри класса. В правилах есть сочетания признаков и цепочки условий.

**Что остаётся улучшить?** Реальные размеченные исследования с независимой
проверкой, валидация правил специалистом, расширение каталога алиасов и
извлечение утверждений из свободного текста. Эти задачи требуют новых данных.

**Чем Qwen отличается от учебной нейросети?** MLP студент обучает на
синтетических сочетаниях фактов и проверяет на отложенной выборке. Qwen3.5-2B
уже обучена разработчиком и подключена через llama.cpp для
выбора пунктов текущего разбора. Сервер проверяет выбор, а пояснение формирует
по экспертным правилам. При неизвестной теме просит уточнение. Собственная
MLP обучается отдельно; Qwen не заменяет этот учебный модуль.

**Что опубликовано на GitHub?** Перед защитой сверить удалённый `main` с
локальным коммитом и открыть README, презентацию и workflow. Наличие
локального файла CI не подтверждает успешный запуск GitHub Actions.
