# Проверка Криптоскопа

Дата: 4 октября 2026 года.

Проверен локальный проект на Windows с Python 3.12.14.
Программа использует стандартную библиотеку Python.

## Автоматические проверки

```powershell
python -m unittest discover -s tests -v
```

Результат: **14 тестов прошли**. Проверены:

- полный и неполный профиль, отрицательные и неизвестные факты;
- минимальное объяснение OR и согласованность прямого и обратного вывода;
- конфликт фраз, приоритет анкеты, источники и даты в отчёте;
- исключение токеномики для проекта без собственного токена;
- наследование и изменение фреймов, поиск пути в семантической сети;
- формулы капитализации и FDV с явно выбранной базой total/max;
- нули, неизвестные значения, некорректные числа и несогласованный supply;
- расхождение исходных чисел с расчётом, устаревший снимок и дата unlock;
- HTTP API, валидация входа, ограничение Origin и недоступные пути.

JavaScript интерфейса также прошёл синтаксическую проверку Node.js.

## Проверка обновлённого дизайна

Интерфейс проверен после применения `frontend-design`:

- В варианте «Досье» редактор прокручивается отдельно, кнопка анализа
  остаётся доступной. Горизонтальной прокрутки страницы нет.
- На ширине 390 px редактор и результат складываются в одну колонку,
  таблица чисел — в две. Проверена полнота сведений 100% и расчёты
  полного учебного профиля. [Мобильный снимок](INTERFACE_MOBILE.png).
- Вкладки переключаются стрелками, Home и End. Фокус переходит на
  выбранную вкладку и имеет видимый контур.
- Вопрос открывает нужную группу и переводит фокус на критерий.
  Редактирование ответа, основания, источника и даты изменило число
  заполненных критериев с 14 до 15, полноту с 54% до 58%.
- Объяснение R16, правила, наследование и связи сети отображаются.
- После открытия нового примера группы сворачиваются, редактор
  возвращается к началу. Неполный профиль даёт 0–100, 18 вопросов
  и 0 замечаний по известным фактам.
- Экспорт JSON и Markdown после редизайна проверен повторно:
  все 26 фактов полного профиля, даты, источники и числа сохранены.
- Контраст основного текста на белом — 14,99:1, вторичного — 5,46:1,
  основной кнопки — 6,67:1, критичного замечания — 6,18:1.
  Пользовательское предпочтение уменьшенного движения учитывается
  при переходах к результату и выбранному критерию.

Временное изменение размера браузера после проверки сброшено.

## Восемь тем и компоновок

Проверены «Досье», «Ночной», «Терминал», «Бумага», «Студия»,
«Компактный», «Фокус» и «Карточки»:

- При каждом переключении значения всех полей и текст результата
  совпали с исходными. Проверка включала изменённое название,
  ещё не отправленное на анализ.
- На обычном экране, при ширине 390 px и 1280 px горизонтальной
  прокрутки страницы нет. На мобильном экране все панели идут
  последовательно; окно выбора прокручивается до восьмого варианта.
- «Ночной» меняет панели местами, «Фокус» размещает разбор под широким
  редактором и показывает шесть числовых метрик в ряд при ширине 1280 px.
  «Карточки» показывают замечания в две колонки на широком экране.
- Выбранный «Ночной» восстановился после перезагрузки. В галерее
  выбран ровно один вариант. Esc закрывает окно и возвращает фокус
  на кнопку «Интерфейсы».
- Экспорт полного профиля в ночной теме совпал с нормализованным
  исходным профилем по всем 26 фактам, основаниям, источникам, датам
  и числам. Markdown совпал с отчётом Python, кроме времени анализа.
- Ошибок и предупреждений в консоли не обнаружено. Синтаксис
  итогового JavaScript проверен Node.js.

с введёнными данными, а не достоверность сведений о реальных проектах.
