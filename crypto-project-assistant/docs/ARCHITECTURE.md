# Архитектура Криптоскопа

`server.py` и CLI вызывают один `ProjectAssistant`.

```text
JSON / текст / форма
  → profile: валидация, assets: алиасы, extract_claims: явные фразы
  → tokenomics: численные сигналы, applicable_facts: применимость
  → ExpertSystem: ProductionEngine + LogicalEngine
  → объяснения, интервал балла, вопросы, рекомендации
  → ModelStore: Bernoulli NB + MLP (результат для сравнения)
  → JSON / Markdown / браузер
  → по запросу: LocalAI → локальный llama-server → пояснение в отчёте
```

Единая база знаний: `data/knowledge.json`. Фреймы и сеть в `ExpertSystem`
загружаются из `.state`, если пользователь сохранял изменения через команды.
Иначе используются значения базы. HTTP API выдаёт актуальные типы и сеть.
Правила не берут критерии или рыночные числа из имени монеты.

Механизм прямого вывода применяет правила в порядке приоритета до отсутствия
новых фактов. Обратный вывод подтверждает каждое полученное заключение.
В трёхзначной логике неизвестное не превращается в ложное: `NOT unknown`
остаётся неизвестным. Вычисленные и явно введённые факты различаются в доказательстве.

`dataset.py` создаёт уникальные комбинации входных фактов и получает метки из
тех же экспертных правил. Отдельные train/validation/test записываются в CSV.
`ml.py` обучает модели без сторонних пакетов. Веса, схема признаков, порядок
классов и SHA-256 базы/датасета сохраняются в JSON. При несовпадении базы
модели не участвуют в распознавании, экспертный вывод продолжает работать.

Изменения пользовательских данных сохраняются атомарно. Сервер слушает только
loopback, ограничивает запрос 256 КБ, проверяет JSON и Origin. Форма помечает
устаревший результат и повторно анализирует профиль перед экспортом.

`local_ai.py` — необязательный HTTP-клиент llama.cpp из стандартной библиотеки.
По умолчанию выключен. По явному запросу получает список моделей и передаёт
ограниченный контекст экспертного разбора в `/v1/chat/completions`. Ответ
добавляется отдельно и не меняет факты или оценку. Настройки записываются
атомарно в `.state/local_ai.json`. Разрешён только loopback, без HTTP-прокси
и перенаправлений; есть таймаут и проверка ответа. Правки формы отменяют
ожидание и не позволяют позднему ответу заменить актуальный результат.
См. [локальную ИИ](LOCAL_AI.md).

Ограничения: локальный словарь алиасов и явных фраз; синтетические данные;
введённые источники не проверяются автоматически; учебные веса и пороги.
Нейросеть не прогнозирует цену или доходность. Фреймы описывают тип, а не
переопределяют правила по своему текстовому содержимому.
