# Итоговая проверка Криптоскопа — 7 октября 2026

Проверены основные действия, граничные входные данные, ошибки сервера,
отмена операций и адаптивные компоновки. Все найденные в этой проверке
ошибки исправлены и повторно проверены. Приложение сохраняет черновик,
объясняет ошибки и позволяет продолжить работу после сбоя.

Среда ручного тестирования: macOS arm64, Python 3.14, браузер Codex,
приложение `http://127.0.0.1:8770`. Настоящий llama.cpp с Qwen3.5-2B
Q4_K_M работал на `127.0.0.1:8080`. Для задержек и ошибок использовался
отдельный временный сервер с изолированными настройками ИИ; после
проверки он остановлен. Фактическое выступление на защите не входит
в программную реализацию; презентация и сценарий подготовлены.

## Ручные сценарии

Действия выполнены через поля, кнопки, вкладки, файловый диалог и скачивание.

| Сценарий | Подтверждённый результат |
|---|---|

| Алиасы и смена монеты | `ＢＴＣ` → Bitcoin/BTC, «эфириум» → Ethereum/ETH; противоречивые вручную заданные поля требуют уточнения |

| Сбой загрузки схемы | Есть повторное подключение; введённое во время сбоя название сохраняется; неправильная схема отклоняется |

## Автоматические проверки

- 57 Python-тестов прошли. Один из тестов перебирает все 26 критериев
  с `true`, `false`, `null` — 78 комбинаций, проверяет границы балла,
  подтверждение выводов и конечный JSON. Также отклоняются NaN, Infinity,
  -Infinity и переполнение `1e309`.
- Дополнительно при аудите прогнаны 158 комбинаций критериев и типов
  числовых полей без неожиданных исключений; ожидаемая валидация сохранена.
- 10 тестов JavaScript прошли: сохранение/восстановление черновика,
  повреждение/версия/размер, запрет хранения и квота, приоритет раннего ввода,
  отключение сервера, неправильный JSON, HTTP-ошибка, таймаут и отмена.
  Это тесты функций настоящего интерфейса с подставленными сбоями.
- Синтаксис JavaScript и команда `week415` проверены успешно.
- CI запускает Python 3.10, 3.12, 3.14, Node.js 22 и демонстрационные
  команды `demo`, `week56`, `week48`, `week415`.

Повторение из каталога приложения:

```sh
python3 -m unittest discover -s tests -v
node --test tests/frontend.test.cjs
python3 -m project_assistant week415
```

40 сочетаний. Фактическая ширина совпала с заданной; горизонтального

остальные настольные варианты показывают кнопки редактора в первом экране.
