# Проверка локальной ИИ — 7 октября 2026

Проверено на macOS arm64 с настоящим `llama-server` **b11461** и
**Qwen3.5-2B Q4_K_M** из `unsloth/Qwen3.5-2B-GGUF`, revision
`f6d5376be1edb4d416d56da11e5397a961aca8ae`.
Весовой файл: 1 280 835 840 байт. Текстовый режим, контекст 8192,
один слот, GPU offload, thinking выключен. Команды Windows описаны,
но на Windows в этом проходе не выполнялись.

## Ручной проход в браузере

| Сценарий | Наблюдаемый результат |
|---|---|
| Подключение по умолчанию выключено | Кнопка вопроса недоступна; обычный анализ работает |
| llama-server не запущен | Понятное сообщение о запуске сервера и проверке порта |
| Модель загружается | Сообщение HTTP 503 с предложением дождаться готовности |
| Сервер готов | «Соединение работает. Модель: qwen-local» |
| Сохранение и перезагрузка | Адрес, включение, имя/автовыбор и таймаут сохраняются |
| Имя missing-model | Перечислена доступная модель qwen-local |
| Внешний адрес | Отклонён; предыдущая сохранённая конфигурация не заменена |
| localhost:8080/v1, имя пустое | Модель выбрана автоматически, адрес нормализован |
| Таймаут 4 секунды | Ошибка допустимого диапазона 5–300 |
| Вопрос по vesting проблемного примера | Настоящий ответ Qwen; балл 7–48, 54% полноты и 11 замечаний сохранены |
| Неполный профиль BTC, пустой вопрос | Bitcoin/BTC распознан, отправлен вопрос по умолчанию; критерии не заполнены моделью |
| Отмена запроса | Интерфейс выходит из ожидания и позволяет отправить новый вопрос |
| Смена примера во время генерации | Новый профиль 0–100; старый ответ скрыт и не подменяет результат |
| Выключение подключения | Настройки сохраняются, кнопка вопроса выключена |
| Экспорт Markdown | В файле есть вопрос, ответ, модель и адрес; экспертный отчёт сохранён |
| Восемь оформлений, desktop 1280 px | Профиль, балл и ответ сохраняются; горизонтального переполнения нет |
| Восемь оформлений, mobile 390 px | Ширина страницы 390 px; четыре вкладки переносятся, ответ и кнопки доступны |

На этом компьютере обработка нескольких коротких запросов занимала
примерно 4–5 секунд по журналу llama.cpp. Это наблюдение о тестовом
компьютере, а не гарантия скорости на других устройствах.

## Автоматические проверки

```text
python3 -m unittest discover -s tests -v
Ran 57 tests in 2.430s
OK
```

Десять новых тестов используют управляемый HTTP-сервер и проверяют
ограничения адреса, типы настроек, восстановление повреждённого файла,
автовыбор модели, контекст и неизменность экспертного результата,
выключенное подключение, некорректный ввод, загрузку/redirect, пустой
ответ/JSON/thinking/ограничение длины, таймаут/обрыв, Origin и CLI.
Это проверки клиента и API; настоящая генерация проверена отдельно вручную.
Также прошли `demo`, `week415`, проверка синтаксиса JavaScript и `git diff --check`.

## Качество текста и ограничения

В первых пробных ответах маленькая модель придумывала зависимость между
спросом и vesting и сокращала диапазон до его нижней границы. Инструкция
уточнена: замечания независимы, балл передаётся готовой строкой диапазона,
значения критериев — «Да», «Нет», «Неизвестно». Повторные ответы использовали
рекомендацию R13 и полный диапазон 0–100. Это не гарантирует правильность
каждого будущего ответа. Текст ИИ остаётся отдельным пояснением и не
переопределяет факты, оценку или доказательства правил.
