# Результаты обучения Криптоскопа

Датасет: 1340 уникальных синтетических векторов; 938 train, 201 validation, 201 test.
Seed: 42. 29 фактов × 2 бита = 58 признаков. Четыре класса: research, revise, blocked, clarify.

Синтетические примеры с метками экспертных правил. Точность показывает воспроизведение этих правил, а не качество реальных монет. Решение и объяснение задаёт экспертная система.

Базовая модель выбирает самый частый train-класс (blocked); test accuracy: 29.85%.

Нейросеть: 58→16→4, tanh/softmax; SGD, 100 эпох. Лучшая эпоха по validation cross-entropy: 23.
Выбор параметров по test не выполнялся. Тестовые метки получены из правил, поэтому измерена только их аппроксимация.
