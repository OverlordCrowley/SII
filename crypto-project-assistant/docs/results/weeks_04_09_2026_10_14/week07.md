# Неделя 7 — продукционные правила и прямой вывод

**Задание:** создать продукционную систему, базу правил и прямой вывод.

**Реализовано:** механизм начинает с известных фактов, применяет подходящие
правила по приоритету, добавляет заключения и повторяет проверку, пока новые
факты перестают появляться. В базе 28 правил; в этом сценарии применились шесть.

## Где смотреть код

- [Продукционная система](../../../project_assistant/production.py): `ProductionEngine.run()`.
- [Согласование двух видов вывода](../../../project_assistant/expert.py): `ExpertSystem.infer()`.
- [Входной пример](../../../examples/ready.json).

## Сохранённый результат

В [week07.json](week07.json) сохранены входной профиль, статус и полная трасса:

| Шаг | Правило | Новый факт |
|---|---|---|
| 1 | R01 | product_evidence |
| 2 | R02 | token_case |
| 3 | R03 | tokenomics_clear |
| 4 | R04 | security_docs |
| 5 | R05 | evidence_ready |
| 6 | R06 | research_ready |

Первые пять заключений используются как посылки R06.
Статус `research`: «Есть основа для углублённого сравнения».
В каждой записи трассы указаны условие, заключение и подтверждающие посылки.
Экспертная система дополнительно подтверждает выведенные цели обратным выводом.

[Снимок входа](ready.snapshot.json) — вымышленный учебный профиль.
Статус отражает сведения в нём, а не независимую проверку проекта.

```sh
python3 -m project_assistant week48
python3 -m project_assistant analyze examples/ready.json --json
```
