# Неделя 6 — AND, OR, NOT и объяснение

**Задание:** добавить логические операции и объяснение результата.

**Реализовано:** безопасный разбор выражений со скобками, вычисление значений,
таблица истинности и читаемое объяснение дерева доказательства.
Приоритет операций: NOT → AND → OR.

## Где смотреть код

- [Текст объяснения](../../../project_assistant/assistant.py): `proof_lines`.

## Сохранённый результат

В [week06.json](week06.json) сохранены шесть вычислений:

| Выражение | Заданные значения | Результат |
|---|---|---|
| `a AND b` | a=true, b=false | false |
| `a OR b` | a=false, b=true | true |
| `NOT a` | a=false | true |
| `NOT a` | a неизвестно | null |
| `a AND b` | a=false, b неизвестно | false |
| `a OR b` | a=true, b неизвестно | true |

Там же находятся 8 строк таблицы `a AND (b OR NOT c)` и реальное объяснение R16:

```text
Аудит и права администраторов не изучены: ДА [R16]
  Аудит доступен для изучения: НЕТ [исходное утверждение]
  Права администраторов разобраны: НЕТ [исходное утверждение]
```

Дополнительно доказано R13: при `has_token=true` и `vesting_disclosed=false`
ветвь `NOT vesting_disclosed` достаточна для OR. Неизвестное значение
`unlock_schedule_known` не превращается в отрицательный факт и не нужно
для подтверждения этой ветви.
