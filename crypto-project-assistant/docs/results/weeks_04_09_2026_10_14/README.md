## Что именно зафиксировано

[manifest.json](manifest.json) содержит исходный Git-коммит, версии среды,
результаты проверок и SHA-256 исходных файлов и сохранённых данных.
Снимок снят с **локальной рабочей версии с незакоммиченными исправлениями**:
указанный базовый коммит сам по себе не содержит всех этих изменений.
Это фиксация результатов на одну дату, а не история выполнения заданий
в шесть разных календарных недель.

Папка публикуется как отчётный материал недель 4–9. В эту публикацию входят
Word-отчёт, текстовые пояснения и данные проверки. Новые изменения кода,
интерфейса, Qwen и презентации в отчётный коммит не включены.
Последующие результаты сохраняйте отдельной датированной папкой, чтобы оставить
этот снимок для сравнения. Учебные операции не должны менять сохранённые файлы
этой папки.
