# Неделя 4 — предметная область, база знаний и семантическая сеть

**Задание:** создать GitHub-репозиторий, выбрать предметную область,
создать базу знаний и семантическую сеть.

**Реализовано:** Криптоскоп анализирует полноту исследования криптопроектов.
[Репозиторий SII](https://github.com/OverlordCrowley/SII) существует.
Знания представлены в JSON отдельно от программы:
26 критериев, 28 правил, 6 типов фреймов, 22 узла сети и 21 связь.

## Где смотреть код

- [База знаний](../../../data/knowledge.json): разделы `criteria`, `rules`, `frames`, `network`.
- [Загрузка базы](../../../project_assistant/knowledge.py): `load_knowledge()`.
- [Семантическая сеть](../../../project_assistant/network.py): `SemanticNetwork`, поиск пути.

## Сохранённый результат

[week04.json](week04.json) содержит реальные размеры базы и найденный путь:

```text
project —has→ token —has→ supply —governed-by→ vesting —scheduled-by→ unlocks
```

Это четыре направленные связи между пятью понятиями. Путь найден программой,
а не подставлен как текст отчёта. [Снимок базы](knowledge.snapshot.json)
сохраняет определения именно на дату этой проверки.

Сеть описывает понятия предметной области: связь «проект → токен» не доказывает,
что у каждого пользовательского проекта есть собственный токен.
Конкретные ответы задаются отдельно в профиле.

## Как повторить

Из папки приложения:

```sh
python3 -m project_assistant network nodes
python3 -m project_assistant network path project unlocks
```

Ожидается тот же путь. Пользовательские изменения в `.state/network.json`
могут изменить сеть; снимок выше отражает исходную базу, без пользовательских добавлений.
