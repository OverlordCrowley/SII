# Неделя 5 — факты, логические правила и обратный вывод

**Задание:** создать логическую модель, записать факты и правила,
реализовать логический вывод.

**Реализовано:** `LogicalEngine` получает цель и ищет правило,
из посылок которого можно её доказать. Конкретные значения фактов передаются
отдельно от определений критериев базы знаний.

## Где смотреть код

- [Логический механизм](../../../project_assistant/logic.py): `LogicalEngine.query()` и `explain()`.
- [Правила](../../../data/knowledge.json): правило `R16`.
- [Учебная демонстрация](../../../project_assistant/week48.py): раздел недели 5.

## Сохранённый результат

Программа получила два явно отрицательных факта:

```json
{"audit_available": false, "admin_controls_known": false}
```

Проверила условие R16:

```text
NOT audit_available AND NOT admin_controls_known → security_gap
```

В [week05.json](week05.json) сохранены вход, цель и дерево доказательства:
`security_gap = true`, правило `R16`, оба дочерних факта имеют `source = input`.
Следовательно, заключение получено из исходных посылок.

Неизвестный факт не заменяется отрицательным. Для недоказанной цели
возвращается `null`, а не автоматически `false`.
