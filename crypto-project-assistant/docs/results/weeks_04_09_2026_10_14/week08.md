# Неделя 8 — фреймы и наследование

**Задание:** описать объекты, свойства, связи и реализовать наследование.

**Реализовано:** `FrameStore` хранит фреймы с родителем и собственными слотами.
Свойства собираются по цепочке родителей; для каждого видно его происхождение.
В базе шесть типов, в проверке создан отдельный учебный экземпляр.

## Где смотреть код

- [Фреймы](../../../project_assistant/frames.py): `describe`, `get`, `create`, `set`.
- [Исходная модель](../../../data/knowledge.json): раздел `frames`.

## Сохранённый результат

Программа создала цепочку `crypto_project → defi → demo_protocol`.
В [week08.json](week08.json) сохранены состояние до переопределения,
состояние после и описание родителя.

| Слот экземпляра | До изменения | Источник |
|---|---|---|
| quote_currency | USD | crypto_project |
| focus | Fees, доход, TVL и права токена | defi |
| name | Учебный протокол | demo_protocol |
| related_node | project | demo_protocol |

Затем `focus` экземпляра изменён на «Локальный фокус исследования».
Его источник стал `demo_protocol`. Родитель `defi` сохранил исходный `focus`.
Слот `related_node` связывает учебный объект с понятием сети; он не создаёт
отдельное ребро сети автоматически.

Несуществующий родитель и цикл наследования отклоняются; это покрыто
тестами `test_invalid_frame_hierarchy_is_rejected` и
`test_multilevel_inheritance_and_local_override` в [журнале](python-tests.txt).
