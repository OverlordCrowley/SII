## Недели 9–10: пользовательские команды

Значения слотов передаются как JSON: строку нужно заключать в двойные кавычки.
Примеры для macOS/Linux:

```sh
python3 -m project_assistant frame create my_protocol defi
python3 -m project_assistant frame set my_protocol focus '"Спрос на сервис"'
python3 -m project_assistant frame find focus '"Спрос на сервис"'
python3 -m project_assistant frame show my_protocol
python3 -m project_assistant network add-node bridge "Мост"
python3 -m project_assistant network add-edge project has bridge
python3 -m project_assistant network related project --depth 2
python3 -m project_assistant network path project unlocks
python3 -m project_assistant network path unlocks project --undirected
```

Для отдельного слота с логическим значением кавычки JSON-строки не нужны:
`python -m project_assistant frame set my_protocol reviewed true`, затем
`python -m project_assistant frame find reviewed true`.
Все команды поддерживают `--state путь.json` **перед подкомандой**.
Например, `frame --state demo-frames.json show defi`.

По умолчанию изменения хранятся в `.state/`; база `data/knowledge.json`
сохраняет исходную модель. Перезапустите сервер после изменений.
Новые фреймы появятся в списке типов проектов, новые понятия — в связанных
объектах, если они связаны с `project` на расстоянии до двух рёбер.
Пользовательские изменения фреймов меняют описание типа; они не переписывают
логические правила и веса оценки. Поиск слотов учитывает наследование.

## Недели 11–12: обучение

```sh
python3 -m project_assistant train --seed 42 --epochs 100
```

Команда пересоздаёт датасет и обученные модели. Данные синтетические:
сгенерированные комбинации положительных, отрицательных и неизвестных фактов,
с четырьмя метками, полученными из экспертных правил. Расчётные признаки
соответствуют допустимым сочетаниям FDV, доли обращения и unlock; при отсутствии
токена они исключаются. Это обучение воспроизведению учебной системы, без
рыночных исходов и без оценки реальных монет.

1340 уникальных векторов: 938 train, 201 validation, 201 test.
Разбиение стратифицировано; совпадающие векторы не попадают в разные выборки.
Признаки — 29 исходных фактов × 2 бита: известность и положительное значение.
Итоговые заключения правил, имя монеты и метка в признаки не входят.

Байес использует сглаживание Лапласа. Нейросеть обучается на train с
перекрёстной энтропией; лучшая эпоха выбирается по validation. Test используется
для итоговой оценки, без выбора параметров. Метрики включают accuracy, macro-F1,
precision/recall/F1 по классам и матрицу ошибок. См. [MODEL_RESULTS.md](MODEL_RESULTS.md).

## Недели 13–14: интеграция

Один входной профиль проходит валидацию, распознавание названия/тикера,
выделение явных фраз, расчёты токеномики, исключение неприменимых фактов,
экспертный вывод и распознавание двумя обученными моделями.
Вкладка «Для защиты» и Markdown показывают результат моделей с областью
применимости. Расхождение явно отмечается; статус и объяснение определяют правила.
Данные не загружаются из внешних сайтов. При изменении базы знаний старые
модели отключаются с предложением повторить обучение.
