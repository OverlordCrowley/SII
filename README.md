# ИИ-помощник по диагностике компьютера

Семестровый проект по дисциплине «Системы искусственного интеллекта».
Предметная область: предварительная диагностика неисправностей компьютера.

Проект объединит базу знаний, логику AND/OR/NOT, продукционный вывод,
фреймы с наследованием, семантическую сеть, байесовский классификатор,
простую нейронную сеть и русскоязычный интерфейс.

Работа выполняется по этапам недель 4–15. Учебные данные синтетические.
